* A 「奶龙OI」Round 3 - 生存大师

** 思路

比较简单的题，遇到石头优先使用石镐，遇到钻石矿或者遇到石头但石镐无耐久使用铁稿；如果遇到石头但两个镐都没耐久或者遇到钻石矿但铁镐无耐久，则不能继续向下挖掘。

** 代码

#+BEGIN_SRC cpp
  #define FAST_IO

  #include "../../templetes.hpp"

  void solve() {
      ll n, a, b; rd(n, a, b);
      vll s; rv(s, n);
      ll cnt = 0;
      for(ll &x : s) {
	  if(x == 1) {
	      if(!(a || b)) break;
	      else if(!a && b) cnt ++, b --;
	      else cnt ++, a --;
	  } else {
	      if(!b) break;
	      else cnt ++, b --;
	  }
      }
      wt(cnt); pc('\n');
  }

  int main() {
      ll t = 1;
      rd(t);
      while(t --) solve();
      return 0;
  }
#+END_SRC

* C 「奶龙OI」Round 3 - 跑酷大神

** 思路

刚开始打草稿会感觉这真的可以算出来吗，但打完草稿后会发现有一点思路。
先把所有数排序。设排序后的数组为：\(a_1 \le a_2 \le \cdots \le a_{2n}\)。

对于任意一种合法摆放/配对方案，把每个数按照大小关系看，可以把总贡献拆成若干段相邻差之和 \(\sum_{i=1}^{2n-1} c_i(a_{i+1}-a_i)\)，其中 c_i 表示方案中跨过第 i 个分界点的次数。
在合法方案中，除了中间这个分界点\(a_n \mid a_{n+1}\)之外，其余分界点被跨过的次数都会成对抵消，不会对最终结果产生额外贡献。
因此整个方案的贡献等价于中间两个数的差\(a_{n+1}-a_n\)。也就是说，不管怎么合法摆放，最后真正留下来的只有排序后中间两个数的差。

合法方案的数量为\((n!)^2\times 2^n\)，可以理解为：
1. 两侧各自内部的排列贡献 n!，共 (n!)^2；
2. 每一对/每一组内部有 2 种交换方式，共 n 组，因此再乘 2^n。
所以总答案为\((a_{n+1}-a_n)\times (n!)^2\times 2^n\)。

结论是：最终答案只和排序后中间两个数有关，即：
\(\text{ans}=(a_{n+1}-a_n)\times(n!)^2\times 2^n\pmod{PMOD}\)。

代码中数组使用 =0-index= 存储，因此排序后的中间两个数就是 =v[n - 1], v[n]= ，所以答案中作差的部分写 =v[n] - v[n - 1]= 。并且由于计算 2^n 和 n! 有时间消耗，因此先预处理这两个，然后在需要的时候取出，节省时间成本。

** 代码

#+BEGIN_SRC cpp
#define FAST_IO

#include "../../templetes.hpp"

const ll maxlen = 1e6+10;
vll s, t;

ll solve() {
    ll n; rd(n);
    vll v; rv(v, 2 * n);
    sort(v.begin(), v.end());
    ll a = ((s[n] * s[n]) % PMOD * t[n]) % PMOD;
    return (((v[n] - v[n - 1]) * a) % PMOD);
}

int main() {
    s.resize(maxlen, 1); t.resize(maxlen, 1);
    for(ll x = 2; x < maxlen; x ++) s[x] = (s[x - 1] * x) % PMOD;
    for(ll x = 1; x < maxlen; x ++) t[x] = (t[x - 1] * 2) % PMOD;
    ll t = 1;
    rd(t);
    while(t --) { wt(solve()); pc('\n'); }
    return 0;
}
#+END_SRC
