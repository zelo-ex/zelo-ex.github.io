* 1.1 什么是因特网

** 1.1.1 具体构成描述
+ 端系统/主机：计算机网络上的所有设备，容纳应用程序，分为服务器与客户，通过通信链路与分组交换机连接。
+ 通信链路：两个设备间数据交流的线路，包含有不同物理媒介。
+ 分组交换机：转发通信链路上的分组，包括路由器与链路层交换机。
+ 分组：发送端系统将数据分段，并为每段添加首部字节形成的信息包。
+ 路由器：通常位于网络核心，用于连接不同网络，工作在网络层，基于 IP 地址转发 IP 数据报。
+ 链路层交换机：通常位于网络边缘的局域网内部，用于连接同一局域网内的端系统，工作在链路层，基于 MAC 地址转发链路层帧。
+ 因特网服务提供商（ISP）：提供因特网服务的机构，最高层 ISP 平级互联，低层 ISP 付费给高层 ISP 来传输数据。

** 1.1.2 服务描述
+ 分布式应用：涉及多个互相交换数据的端系统的应用。
+ 套接字接口：一套发送程序必须遵循的规则集合，规定了发送程序交付数据的方式。

** 1.1.3 什么是协议
+ 协议：定义了在两个及多个通信实体之间交换的报文的格式和顺序，以及报文的发送/接收或其他事件所采取的操作。
  （协议三要素：语法、语义、时序）
+ 人与人的类比：问“几点了”、对方回答，请求与应答的格式、顺序和动作构成一次协议交换。

** 小测
1. 什么是端系统？什么是分组？
   端系统：因特网内所有的设备（PC、手机、服务器等）。
   分组：端系统将数据分段，每段加上首部（header）形成的信息包。
2. 路由器和链路层交换机大致区别？
   路由器：位于网络核心，属于网络层，与其他网络上的路由器交换数据，通过 IP 地址传输 IP 数据报。
   链路层交换机：位于网络边缘的局域网内部，属于链路层，与其他端系统相连，通过 MAC 地址传输链路层帧。
3. 协议的三要素是什么？
   语法、语义、时序。
4. 用 3 句话解释“协议”，不背原文。
   协议是通信实体间交流的规范，包含语法、语义、时序三个要点，有多种不同的协议，如 TCP 协议、IP 协议等。
5. “因特网”从构成角度和服务角度分别怎么描述？
   构成角度：端系统、通信链路、分组交换机、协议、ISP 等。
   服务角度：分布式应用、为分布式应用提供通信服务、套接字接口。

** 必会公式

| 名称                         | 公式                                 | 说明                               |
|------------------------------+--------------------------------------+------------------------------------|
| 传输时延                     | \(d_{trans}=L/R\)                       | L 是分组长度，R 是链路速率         |
| 传播时延                     | \(d_{prop}=d/s\)                        | d 是距离，s 是传播速度             |
| 节点总时延                   | \(d_{nodal}=d_{proc}+d_{queue}+d_{trans}+d_{prop}\) | 四类时延相加                       |
| 流量强度                     | \(La/R\)                             | L 分组长度，a 到达速率，R 链路速率 |
| 吞吐量                       | \(\min(R_s,R_c)\)                      | 瓶颈链路决定                       |
| 存储转发，N 条链路，单分组   | \(N \cdot L/R\)                          | 忽略传播和处理                     |
| 存储转发，N 条链路，P 个分组 | \((N+P-1)\cdot L/R\)                     | 连续发送，忽略传播和处理           |

* 第一章公式速查卡

#+BEGIN_SRC text
传输时延 = L / R
传播时延 = d / s
节点总时延 = 处理 + 排队 + 传输 + 传播
流量强度 = L * a / R
吞吐量 = min(源到目的路径上的瓶颈速率)
电路交换用户数 ≈ 链路总速率 / 每用户速率
存储转发 N 链路单分组 ≈ N * L / R
存储转发 N 链路 P 分组 ≈ (N + P - 1) * L / R
#+END_SRC

单位坑：

+ 1 Byte = 8 bit。
+ 网络速率常用 Mbps、Gbps，是 \(10^6\)、\(10^9\) bit/s。
+ 传播速度：铜/光纤常取 \(2\times10^8\) m/s，无线约 \(3\times10^8\) m/s。
+ 不要混淆“传输时延”和“传播时延”。
